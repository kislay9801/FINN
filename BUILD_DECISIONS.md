# Build decisions

- **One Next.js 16 app.** API routes, UI, scheduled endpoint and server-only providers deploy together to Vercel. No queue cluster or agent framework. Plain scoped CSS and native dialogs were chosen over a UI framework to control the editorial design and reduce dependencies. SVG sparklines show actual observations; tables communicate financial comparisons more precisely than decorative charts.
- **Evidence before inference.** No API key is assumed. The default experience retrieves original passages, shows real comparisons, and tells the user when analysis requires configuration. This is deliberately different from passing off templated text as AI research.
- **AI choice.** Configurable OpenAI-compatible chat completions, default model `gpt-4.1-mini`. One bounded structured call handles all eight research modules and an optional question. Deterministic classification, arithmetic and alerting cost no model tokens. Model name is configurable because account availability and pricing vary. Live model quality/cost was not benchmarked without a key.
- **Deep case, general plumbing.** Infosys provides five transcript periods and five actual guidance revisions. Annual CC growth is compared to annual CC growth. The deterministic extractor is issuer/layout gated; it refuses other companies' layouts. Ad-hoc discovery and retrieval generalize through the NSE directory and Screener document links. Four additional candidates and Wipro have verifiable cached libraries.
- **Persistent fallback.** Browser-local user state and local server cache enable immediate evaluation. Optional Supabase REST supplies durable hosted cache and database normalization. No mandatory account setup. Hosted persistence and cron need deployment validation.
- **Source honesty.** Official NSE data was accessible without anti-bot workarounds. Snapshot dates are preserved. A quiet Saturday feed stays quiet. Thirty-day exploration reveals historical records. Yahoo EOD is never described as live streaming.
- **Guidance judgment.** Revisions are separate observations of management's changing outlook, not independent pledges. Exceeding a revenue-growth range counts as delivered. Interim outcomes do not settle full-year guidance. Adjusted and unadjusted margins are not silently mixed.
- **Next steps.** Add issuer-independent table extraction with human-verifiable source cell coordinates; explicit transcript promise extraction schemas; comparable four-quarter operating-margin outcomes; better semantic retrieval; OCR; distributed scheduling/rate limiting; authenticated user rule synchronization; Web Push. Improve near-duplicate event grouping without hiding separate regulatory disclosures.
